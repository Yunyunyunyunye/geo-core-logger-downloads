适用于野外地质编录的离线工具，提供 **Windows 电脑版**和**安卓手机版**。

## 1.66 编录小结与描述压缩

- 侧栏新增「编录小结」。先选择钻孔，预览后导出 Word。孔类型、倾角、冲洗液漏失段、溶蚀补充和存在的问题随钻孔保存；孔深、水位、采取率、含水段、软弱段和 RQD 从现有编录计算。
- 压缩提示词可在导入页修改，并恢复默认。修改只保存在本机，不进入备份或云同步。
- 50 字及以内的描述不压缩；超过 50 字才压缩到 50 字左右。只压缩原文已有内容，不编造。描述不写岩性，只保留颜色、结构、构造，各项用中文逗号。
- Android 1.66（versionCode 67）。手机、电脑和网页一起更新，无需新 SQL。校验值见 [SHA256SUMS.txt](SHA256SUMS.txt)。

## 1.64 一致性核查与地质描述压缩

- 新增「一致性核查」，先选择钻孔。分层和回次分开比对；孔深、标高、冲洗液、水位和水文来源先统一单位再比较。每一条差异都要人工核对，不会自动覆盖。能对应已保存地质资料的，点「使用地质导入信息」只改这一条。相关数据变化后，原来的核对失效。
- 地质资料中地层和回次分开提取。只提供止深时，首层、首回次起深为 0，其后缺失的起深取上一条止深。分层采取率按分层岩芯长和层厚计算，回次采取率按回次岩芯长和回次进尺计算，两者不混用。
- 「压缩地质描述」单独操作。50 字及以内保持原文；超过 50 字才压缩到 50 字左右，只保留岩性、颜色和结构构造，可以舍去水文、工程内容，不得凭空增加。原文保留，压缩结果可预览和编辑。
- 岩石名称去掉明确的地层代号，源表原名仍保留。记录表描述按实际宽度折行；超过固定行数时明确报出该层，不再静默截断。
- 清除本孔地质资料需要两次确认，钻孔、水文报表和已有工程、RQD 填写保留。地质资料随编录备份和云同步保存，不含模型密钥。
- Android 1.64（versionCode 65）。手机、电脑和网页一起更新，无需新 SQL。校验值见 [SHA256SUMS.txt](SHA256SUMS.txt)。

## 1.60 智能地质资料导入与统一设置

- 手机首页、电脑侧栏统一从「设置」管理云同步、备份和多套模型接口。密钥只在会话或安装版加密保险库保存，不进入编录备份与云同步。
- 地质资料支持 xlsx/xlsm、多工作表和合并表头。选孔、选文件后，首次可用模型识别字段，经预览确认保存规则，同结构文件后续由程序直接提取；可手动修正字段与单位，宏及模型生成的代码均不执行。
- 整孔长描述可分批精简，保留完整原文和可编辑描述；校验层编号、深度缺段、重叠、重复及孔号冲突，确认后一次性导入，取消或错误不产生半批记录。
- 回次、岩芯长度和采取率可选择导入；不自动填写 RQD，保留原有开关与岩芯段。旧标准模板、水文照片识别及 Excel 校对继续可用。
- Android 1.60（versionCode 61）；建议手机与电脑一起更新，无需新 SQL。校验值见 [SHA256SUMS.txt](SHA256SUMS.txt)。

## 1.59 钻孔类型

工程+水文孔自动启用RQD，柱状图可选1:200或1:500。水文孔进入专属预留页。在钻孔管理可修改孔型，旧孔按原RQD开关自动归类。

## 1.58 导入入口整理与可收缩侧栏

- “地质资料导入”独立入口，先选孔，再选择Excel并预览确认；可下载原模板，分层/回次深度按米，进尺及岩芯长度按厘米。重复导入按原记录更新，保留原RQD岩芯段和开关，预览期间本孔资料改变会阻止覆盖。
- 侧栏可收缩并记住本机状态；“导入备份”“云同步与备份”固定在末尾组。未开启RQD的孔默认折叠，以紧凑列表展示，地质导入不再自动开启RQD。
- “水位变幅”“冲洗液消耗量”维护入口移到“水文报表导入 → 选孔 → 水文绘图资料”，返回保留当前孔；柱状图移除旧编辑入口，原数据继续用于绘图。照片识别结果不自动覆盖绘图资料。
- 安卓1.58（versionCode 59）；两端一起更新，无需新SQL。

## 1.57 水文报表先选钻孔

- 先从列表选择已有钻孔，或填写新水文孔号后点击“进入钻孔”，再选择照片、识别及导入Excel校对。
- 进入后显示固定孔号，通过“切换钻孔”或返回重新选择；识别等操作进行中不可切孔，暂停后需等在途结果保存。
- 列表包含已有编录孔、水文结果及本机照片队列，并显示数量；结果删空后仍能找到原照片队列，切换账号需重新选孔。
- 安卓1.57（versionCode 58）；手机电脑一起更新，无需新SQL。

## 1.56 RQD钻孔备忘录

- 进入RQD选择钻孔，展开顶部“本孔备忘录”，支持多行文字。填写后点击“保存备忘录”，离开前请保存；可取消修改，最多20000字。
- 每孔独立，离线重开可查看，随编录JSON单孔/全部备份及云同步保存；钻孔改名保留，清空RQD岩芯不清备忘录。
- 旧备份没有备忘录字段时保留现有文字；编辑期间同一份备忘录更新会拒绝旧输入覆盖，保留输入供重新核对。
- 安卓1.56（versionCode 57）；手机电脑请一起更新，无需新SQL。

## 1.55 水文问题定位与原地校对

- 问题栏只显示实际异常，界面和Excel中正常行留空；核对状态单独显示，水位原文独立保留。
- 当前孔顶部汇总全部问题，点击定位到对应回次；Excel校对导入后重新检查缺段、重叠、孔深错误。
- 点“校对 / 修改”在当前回次内展开表单，保存或取消后收起，不再跳到底部。
- Flash提示词增加详细取列规则及三个虚构示例，区分相邻耗量列和两种水位，不确定立即标模糊留空、保留行，不反复猜测或推算。按默认/high准备，保留用户参数；尚未用真实模型测量耗时和准确率变化。
- 安卓1.55（versionCode 56）。两端一起更新，无需新SQL。

## 1.54 修复重新识图

- 修复删除水文结果后，重新选择原照片直接显示“已完成”却没有结果的问题。旧完成任务在结果删空后恢复为待识别，点击“开始 / 重试未完成”重新调用模型。
- 已删除记录不再触发识别去重；本孔仍有该照片有效结果时继续避免重复计费，其他孔的数据保留。
- 安卓版本号提升至1.54（versionCode 55）。两端一起更新，无需运行新的SQL。

## 1.53 更新与Excel校对

- 水文支持“导出本孔Excel → 在Excel修改 → 导入Excel校对结果”。保留隐藏记录ID和校对信息，整行排序；改孔深仍更新原行，不重复新增。导入前确认更新与新增数量，确认期间数据变化会阻止覆盖。Excel删行不会删除软件已有记录。
- 水位列纠正为“提钻后、下钻前”，升降自动计算“提钻后－下钻前”，任一为空则留空，负值保留。历史数值不交换，旧版Excel按旧列的实际含义转换。
- 单位进尺/时间消耗量在原值除以1000后四舍五入保留两位；导入时直接读取表中数值，不再除1000。未改的显示值回导会保留原始识别精度。
- RQD页可直接导入软件导出的长度表，自动读取“按层”“按回次”两张表。单位米换算一次，保留进尺与孔深；合计未改时保留原岩芯段明细。多条拆分记录的合计被修改时会明确提示，避免猜测分摊。
- 新增“删除本孔全部水文结果”：确认孔号/条数后再输入孔号确认；只同步删除该孔结果，其他孔和本机照片保留。

手机与电脑请一起更新，无需运行新的云端SQL。建议更新前分别导出编录JSON和水文JSON备份。

## 水文报表导入（1.50新增）

手机和电脑都可选照片识图。先选钻孔编号，再在“模型设置”填写自己的视觉模型接口地址、模型名和API Key，保存后添加照片并开始。不同孔照片分批选择，例如ZK001、ZK002；同一孔的多张照片结果按孔深统一排序。

1.51起，先填接口地址和自己的Key，点击“获取模型列表”即可下拉选择。服务不提供列表时可手动填写；列表不一定注明识图能力，请选择支持图片的模型，再点击保存。

耗量按原值除以1000，水位按观测孔深匹配回次止深。空白不补0，模糊行保留候选并标记；缺段、重叠、重复会在问题栏指出。可校对并按孔导出Excel。

同账号设备打开“水文报表导入”后同步结果及校对修改，照片和Key不进入云同步。Key默认仅本次使用，安装版可选择本机加密记住。识别需联网并使用用户自己的模型额度；未内置任何模型账户或Key。

水文数据使用本栏目独立的JSON备份，原有编录备份不包含水文模块。未登录本机工作区与账号工作区分开，可显式导出再导入。识别时保持App在前台，后台中断后可手动继续，失败不自动重复请求。

`Source code.zip` 只是此下载仓库的说明文件，并不是安装包。当前没有 iPhone 原生安装包。

## 手机和电脑一起用

1. 两台自己的设备登录同一个邮箱账号。首次注册需要确认邮件。
2. 手机离线可以继续保存记录；联网且已登录后自动同步。
3. 电脑在线时约每 30 秒检查更新，也可点击“立即同步”。不同记录自动合并，同一条记录两边都改过时需要选择版本。
4. 首次连接且两边都有记录时，先分别导出备份，再按提示选择整份数据；没有共同基线时不会猜测合并来源。
5. 给别人用时，让对方注册自己的账号。不同账号不共享云端记录，不要把自己的账号密码发给别人。

未登录也能离线编录、计算、导入和导出；此时数据仅保存在当前设备。

## 备份与恢复

- 使用期间有变化时，每 10 分钟自动备份，本机保留最近 30 份。
- 删除、替换、恢复前另存操作备份，最近 20 份。
- 手动备份可以命名，不自动覆盖，重要节点建议另存一份 JSON 到其它文件夹。
- 已配置云服务且已登录时，云端按日保留 30 天、按周保留 12 周；无变化不重复生成。离线期间属于该账号的档案会在联网同步时补传，手动云备份不自动删除。
- 恢复只先作用于本机，并暂停自动同步；核对无误后再点“确认恢复并同步”。
- 手机被系统停止运行或应用关闭时，定时备份不会持续执行；每次正常保存的编录仍先落在本机。

## 从旧版升级

**先在旧版导出全部 JSON 备份，并确认文件已保存，再安装新版。**

安卓旧版若出现“签名不一致”“与现有安装包冲突”，不能直接覆盖安装。不要在没有备份的情况下卸载；请先保留旧版、导出备份，确认可用后再处理安装冲突。1.49 起使用固定发布签名，后续版本沿用同一签名。

Windows 更新沿用同一用户数据目录，不会主动迁移手机或浏览器数据；首次使用电脑版可导入手机 JSON 备份。免安装版的数据不跟随 exe 移动。
